Zochova,
an open source chess engine under the GNU General Public License by Gabor Buella written in C++, compliant with the Chess Engine Communication Protocol. Zochova is a bitboard engine, and requires some Boost libraries, such as Boost.Signals 1, an implementation of managed Signals and slots for Observer pattern, and uses the ProDeo open source code opening book by Ed Schröder 2. Sliding piece attacks are calculated with some bit-twiddling and loops on the fly 3. Its search is basically PVS with verified nullmove pruning, and late move reductions.
