Hopeless, (Hopeless Chess)
an open source chess engine by Pawel Koziol, written in Pascal using WBUnit by Maciej Szmit for WinBoard compliance. Early versions were incorporated inside the stand-alone chess program Clericus written in Delphi, featuring an own GUI 1. Hopeless played the PCCC 2006. In 2020 Hopeless and Clericus were revived by Roland Chastain, using Free Pascal and Lazarus 2.
