Chess,
a chess program by John Krause, written in 6502 machine language with versions for Commodore VIC-20 (with at least 8 KiB expansion), Commodore 64, Atari 8-bit and Apple II, published and described in the Compute! December 1984 issue. The program was printed in Basic syntax with machine code in Data statements, along with a leading read and poke loop, to read the data and store it as executable code in memory. The program applies alpha-beta with a depth from two to six plies depending on level 1-5, and a material only evaluation with {1,3,3,5,9}-point values. An improved 8086 version of the program for the IBM PC was published a few months later 1. The C64 version was also released in 1986 as Chess Master by FHD Software 2.
