Deep Pink, 1
an experimental open source chess engine by Erik Bernhardsson, written in Python as an attempt to learn and play chess. Deep Pink applies negamax alpha-beta and a deep neural network as evaluation function, using Theano, python-chess, and Sunfish 2. The input representation seems similar to Octavius with 12x64 nodes, not feeding in side to move, castling rights, and en passant target square. The first hidden layer has 2048 neurons as well. Bernhardsson used a GPU instance to train the net with 100M games for about four days using stochastic gradient descent with Nesterov momentum 3 4 5 6.
