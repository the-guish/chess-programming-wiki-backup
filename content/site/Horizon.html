Horizon, (Horizon Chess)
a WinBoard compatible chess engine by primary author Ron Murawski and chess advisor and book author Jim Monaghan. Written in C, the programming started in July 2001, first release was already in October 2001. Initially running atop a much-modified version of Colin Frayn's open-source Beowulf infrastructure, there's very little of Beowulf that remains within Horizon and less with each release 1.

Features

2

  • Iterative Deepening
  • Aspiration Windows (Asymmetric on Side to move)
  • Principal Variation Search
  • Move Ordering
    • Internal Iterative Deepening
    • Killer Heuristic with two Killers and one Mate Killer per Ply
  • Selectivity
    • Fractional Extensions / Reductions
    • Mate Threat Extensions
    • One Reply Extensions
    • Check Extensions (Discovered Check)
    • Recapture Extensions
    • Passed Pawn Extensions (7th Rank)
    • Quiescence Search with Check Extensions
    • Adaptive Null Move Pruning (R 2-4.5, Up to 3 Null Noves per Line)
    • Null Move Verification
    • Futility Pruning
    • Adaptive Razoring
    • Reductions (for non-dangerous moves)

Tournament Play

Horizon played the WCRCC 2007 and WCRCC 2008 Annual ACCA World Computer Rapid Chess Championship.
