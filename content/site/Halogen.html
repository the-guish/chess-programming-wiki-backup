Halogen,
an UCI compliant open source chess engine by Kieren Pearson, written in C++, licensed under the GPL v3 and first released on GitHub in June 2019 1. Since version 7 in September 2020, Halogen features an own, incrementally updated neural network for its evaluation function, inspired by Stockfish NNUE. Halogen 8 features a larger network than Halogen 7, but runs significantly faster due to improvements and optimisations, best if compiled for AVX2 instructions. Its development and testing was supported on the OpenBench framework. Networks are trained through a private, from scratch C implementation created in collaboration with Andrew Grant 2.
