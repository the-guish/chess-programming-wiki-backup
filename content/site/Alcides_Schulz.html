Alcides Schulz,
a Brazilian professional software developer and programmer, currently working in the United States. Alcides combined his hobbies of programming and chess 1 to develop his open source engines. The matured Tucano 2, first released in 2011, is written in C - the didactic Enxadrista first published in 2018, is written in C# 3, and provides a detailed, elaborate documentation in Portuguese language in form of source code comments 4.
