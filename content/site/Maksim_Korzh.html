Maksim (Maksym) Korzh, alias Code Monkey King,
an Ukrainian freelancer and computer chess programmer. As a computer chess aficionado and chess programming enthusiast, he learned JavaScript, Python and C languages, as well as x86 Assembly. He started freelancing at Upwork but soon moved to YouTube to create a channel dedicated to web scraping and web development 1, and further combined his profession with his computer chess activity for a YouTube channel dedicated to chess programming - where he introduced chess programming topics along with the development of various chess engines for didactic purpose 2.
