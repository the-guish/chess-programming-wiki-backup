Description

given in 1999 3 :

Ruy-Lopez is a standard alpha-beta searcher, with some innovative forward pruning methods. The evaluation function is quite sophisticated and also slow. After four years programming Torquemada 4, a Spanish Checkers 5 program, we began programming Ruy-Lopez in July'97 just for fun. This is a very young program, so we have much room for improving. Currently Spanish Computer Chess Champion.
