David John Barnes,
a British computer scientist and lecturer at School of Computing, University of Kent. His research interests include software testing and biological modelling. He is co-author of the introductory Java programming using the BlueJ IDE 1. As a club-level chess player, he is author of the PGN processing tool pgn-extract 2. Along with co-author Julio Hernández-Castro, David J. Barne researched and elaborated on engine analysis for cheating detection in chess 3, and also published the C++ and Java source code for an UCI based analyser for chess games in PGN notation 4.
