Wukong JS, (WukongJS)
a open source chess engine and user interface by Maksim Korzh. Wukong JS is written in JavaScript, either to run as HTML document inside a web browser 1, or in UCI mode via Node.js. Further, Wukong JS offers an API to embed Wukong JS in third party websites.
