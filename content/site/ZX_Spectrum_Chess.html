ZX Spectrum Chess, (Chess, Masterchess)
a chess program for the ZX Spectrum by Anthony Adam, written in Z80 assembly language, distributed in 1982 by Psion Software with Mikro-Gen, and Sinclair Research, not to confused with the Spectrum Chess program by Artic Computing 1. Apparently, the program was forerunner of the 1984 Master Chess release for Amstrad CPC by Amsoft / Mikro-Gen 2. In 1987, a Mastertronic program named Master Chess was also available not only for Z80 but also 6502 computers 3 for instance Atari 8-bit and Commodore 64.
