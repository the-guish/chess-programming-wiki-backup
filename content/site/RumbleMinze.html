RumbleMinze,
an UCI compliant open source chess engine by Erik Madsen, written in C# to run under the Windows .NET framework. It was released in April 2012 1, and is predecessor to MadChess which followed a few months later 2 introducing a new move generation technique using the C# yield statement 3 4 5 6.
