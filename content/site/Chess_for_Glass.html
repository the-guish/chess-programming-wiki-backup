Chess for Glass

Home * Engines * Chess for Glass

Chess for Glass,
written by Aart Bik, is Glassware 1 2 that runs directly on a Google Glass device. The user can enter moves by simply saying the moves (voice input feature), or by using the touchpad. Other features include a choice in board color, spoken move announcements, and the ability to import any third party chess engine to replace the friendly built-in Java engine. Chess for Glass recognizes all ChessBase compatible engines that are installed on the same Glass device, and supports both the popular UCI and XBoard/WinBoard protocols.
