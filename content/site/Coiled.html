Coiled,
an UCI compliant chess engine by Oscar Gavira, written in C, first released in 2013. Coiled 0.6, released in July 2018 is available as 32-bit and 64-bit executable for Windows 1. Coiled-NNUE 0.7 was released in August 2021 as Open Source licensed under the GPL v3.0, using a Stockfish NNUE network with CFish derived probing code 2 3.
