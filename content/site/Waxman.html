Waxman,
also known as Pocket Chess for Windows, is a shareware chess program by Ivan Bacigal from the 90s, Waxman 1.1 in 1991 as MS-DOS engine, Waxman 1.2w in 1992 running under Windows. In 2008, Waxman became Chess Engine Communication Protocol compatible 1. The program uses 10x12 board representation, incremental attack updates, alpha-beta search with iterative deepening, aspiration window, killer moves and refutation moves, history heuristic - all pretty cutting-edge back in 1990. Later on, Ivan Bacigal added null move pruning and tried several types of futility pruning. The newer WinBoard versions also use internal iterative deepening and late move reductions, and since 2017 tapered evaluation 2. Waxman's name resembles the Russian word for chess Шахмат, while its original name was VaxMan, an attempt to camouflage the program as a DEC VAX management utility 3.
